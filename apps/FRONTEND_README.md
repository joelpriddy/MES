
# Frontend Scaffolding (Vite + React + TypeScript)

Run these commands manually (Node 18+ recommended):

```bash
npm create vite@latest apps/Admin.UI -- --template react-ts
cd apps/Admin.UI && npm install
cd ../../

npm create vite@latest apps/Portal.UI -- --template react-ts
cd apps/Portal.UI && npm install
cd ../../
```

Run with:
```bash
cd apps/Admin.UI && npm run dev
cd apps/Portal.UI && npm run dev
```
